# pureTV Launcher 0.2.1

新增 layout.json 版本 2：home 与 apps 两页分别定义列数及有序卡片，配套管理器的全局电视画布可拖动排序、调整名称、图标和颜色。应用入口只接受已安装、启用、可启动的用户应用；不兼容旧版 apps.json。

包名继续为 com.ecojust.puretv，沿用 0.2.0 发布证书，可直接升级。若从 com.ecojust.cleanyourtv 迁移，需独立安装并重新选择默认桌面。

仅发布启动器 APK，附 SHA256 和包名／版本／证书元数据。电脑管理器：[Manager 0.2.1](https://github.com/ecojust/pureTV/releases/tag/desktop-v0.2.1)。
