# pureTV Launcher 0.3.0

采用新的 pureTV 图标。首页和其他应用页均从 layout.json 定义加载，管理器的全局电视画布可拖动卡片，调整两页独立列数、名称、图标与颜色。只允许添加已安装、启用且可启动的用户应用；不兼容旧 apps.json。

包名 com.ecojust.puretv，沿用 0.2.0 发布证书，versionCode 9，可覆盖升级。更早的 com.ecojust.cleanyourtv 是独立应用，安装后需重新选择默认桌面。

此 APK 与 resource/puretv-launcher 中的文件一致，附 SHA256、版本、源代码树和签名元数据。对应源码与封面示例见[资源文件夹](https://github.com/ecojust/pureTV/tree/master/resource/puretv-launcher)。

电脑端：[pureTV Manager 0.3.0](https://github.com/ecojust/pureTV/releases/tag/desktop-v0.3.0)。
